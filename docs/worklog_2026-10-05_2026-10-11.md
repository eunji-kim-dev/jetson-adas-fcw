  - 150프레임 모두 값 일치
  - GPU 읽기 약 0.047 ms
  - 먼저 복사한 뒤 읽는 경우와도 거의 차이 없음: 0.074 vs 0.072 ms
- Jetson에 `jetson_multimedia_api`, `libnvbufsurface.so` 둘 다 설치되어 있는 것도 확인

**알게 된 점**

- 입력 배열을 처음부터 고정 메모리에 만드는 방법은 약 0.7 ms 정도만 줄일 수 있음
  - CPU 전처리 경로를 조금 더 줄이는 보조 최적화 정도의 의미
- 고정 메모리를 TensorRT 입출력 메모리로 직접 쓰는 방법은 적용하지 않기로 함
  - GPU 전처리에서는 남아 있는 복사 비용이 0.16 ms 정도뿐이고
  - 고정 메모리를 GPU가 읽는 속도도 일반 GPU 메모리보다 느리기 때문
- 카메라 버퍼를 GPU가 직접 읽는 방식은 동작 확인 완료
  - 10/8 카메라 측정에서 실제 파이프라인에 적용 예정

### 3. LEAD 규칙 Jetson 평가·최종 조합 확정

**작업 내용**

- Jetson FP16 288 환경에서 LEAD 규칙 5개 조합을 비교함
  - 기존 7개 규칙
  - +rank
  - +rank,bottom
  - +rank,bottom,edge
  - +rank,bottom,edge,cropedge
- 평가 데이터는
  - 본 평가셋 16개
  - 이륜차 5개
  - 정상 주행 10개
- K=70의 효과와 06·08번 차량 박스를 프레임 단위로 확인
- 20번 오경보와 13번 잘못 잡힌 버스는 결과 영상을 직접 확인

**검증 결과**

- 본 평가셋에서는
  - 기존 7개 규칙
  - +rank
  - +bottom
  - +edge
  모두 결과가 같았음
  - Miss 3개: 01·08, 16은 경고가 늦음
- `cropedge`까지 켜면 08번이 127프레임에서 경고되면서
  - Miss가 3개 → 2개로 감소
  - 남은 문제는 01과 16 지연
- K=70 결과
  - 03 첫 경고 36프레임
  - K=400일 때는 41프레임
  - 06 갈색 SUV는 66프레임 경고
  - 10/4에 예상했던 결과와 실제 Jetson 결과가 같았음
- 06번은 cropedge를 켜면 같은 SUV의 트랙 ID가 `6 → 16`으로 바뀜
  - 이 때문에 경고가 66 → 72프레임으로 약 0.4초 늦어짐
  - 영상에서 같은 차량임을 직접 확인
- 08번 127프레임 경고는 정상 동작
  - 대상 차량 ID18이 맞음
  - 기존 crop 영역에서 잘려 높이 62였던 박스가 cropedge 적용 후 높이 96으로 잡힘
  - 그 결과 TTC 2.3초로 DANGER 판정
- 정상 주행 10개에서는 모든 조합에서 DANGER 오경보 0
- CAUTION은 6_014 한 건
  - 기본 98프레임, cropedge는 83프레임
  - 라이다 기준 실제 TTC 최저 2.2초라 오경보가 아니라 정상 반응
- 이륜차 세트
  - 12·14 Miss
  - 13은 버스를 잘못 LEAD로 선택
  - 20은 cropedge에서만 37프레임에 맞은편 차량 오경보 발생
- `bottom` 규칙은 Jetson에서는 효과가 없었음
  - x86에서 보였던 07·16 개선이 재현되지 않음

**알게 된 점**

- 최종 LEAD 조합은 아래로 확정
  - `overlap,history,gap,passby,gate,bonnet,hold,rank,bottom,edge,cropedge`
- 다만 코드 기본값은 계속 OFF로 둬 기존 골든 결과는 유지
- cropedge는 본 평가셋의 08번을 살렸고 정상 주행 10개에서도 새로운 오경보가 생기지 않았음
- 20번 문제는 오토바이 문제가 아니라 맞은편 차량이 후보로 들어오는 문제라 별도 2단계 문제로 둠
- 13·20은 영상을 확인한 뒤 현재 단계에서는 우선 그대로 두기로 함
- 06번 0.4초 지연은 cropedge 자체 문제라기보다 **트래커가 같은 차량에 새 ID를 부여한 문제**
  - 트래커 개선 과제로 넘김
