# Troubleshooting

Blackbox ADAS 프로젝트를 진행하며 겪은 주요 문제들과 원인 분석, 해결 과정을 정리합니다.

---

## 1. ROI 밖 차량은 검출되지만 정면 차량이 검출되지 않는 문제

**상태: 해결**

### 증상

화면 왼쪽 ROI 외부의 차량은 정상적으로 검출되었지만, 주행 ROI 내부에 있는 정면 차량은 제대로 검출되지 않았습니다.

### 원인

처리 순서를 확인한 결과 다음과 같이 구성되어 있었습니다.

```text
원본 프레임
→ 초록색 ROI 오버레이 적용
→ 오버레이가 적용된 프레임으로 YOLO 추론
```

ROI 내부 차량은 반투명 초록색 오버레이로 픽셀 색상이 변경된 상태로 모델에 입력되었고, ROI 외부 차량은 원본 색상이 유지되어 상대적으로 더 잘 검출된 것이었습니다.

### 해결

YOLO 추론을 원본 프레임에 먼저 수행하고, 추론이 끝난 뒤 시각화용 ROI를 그리는 순서로 변경했습니다.

수정 전:

```text
ROI 시각화
→ YOLO 추론
→ 바운딩 박스 출력
```

수정 후:

```text
원본 프레임 YOLO 추론
→ ROI 시각화
→ 바운딩 박스 출력
```

핵심 코드는 다음과 같습니다.

```cpp
detections = detectObjects(
    net,
    frame,
    confidenceThreshold,
    nmsThreshold
);

// 추론 완료 후 ROI 표시
cv::Mat overlay = frame.clone();
cv::fillConvexPoly(
    overlay,
    drivingRoi,
    cv::Scalar(0, 255, 0)
);
```

### 검증

수정 후 결과 영상에서 정면 차량과 측면 차량이 모두 검출되는 것을 확인했습니다.

## 2. 원거리 차량이 검출되지 않는 문제

**상태: 해결**

### 증상

가까운 대형 차량은 검출되었지만, 정면에서 작게 보이는 원거리 차량은 프레임에 따라 검출되지 않았습니다.

### 원인

검출 신뢰도 기준이 다음과 같이 설정되어 있었습니다.

```cpp
constexpr float confidenceThreshold = 0.40F;
```

원거리 차량은 화면에서 차지하는 픽셀 수가 적어 YOLO 신뢰도가 상대적으로 낮게 산출되는데, 0.40 미만의 검출 결과가 모두 제거되면서 원거리 차량이 통째로 누락되었습니다.

### 해결

신뢰도 기준을 다음과 같이 낮췄습니다.

```cpp
constexpr float confidenceThreshold = 0.25F;
```

### 검증

수정 후 이전에 누락되던 작은 정면 차량과 원거리 차량이 더 많이 검출되는 것을 확인했습니다. 다만 신뢰도 기준을 낮추면 오검출 가능성도 함께 증가하므로, 다양한 영상을 대상으로 한 추가 검증이 필요합니다.

## 3. 동일 차량의 Tracking ID가 계속 변경되는 문제

**상태: 1차 개선 완료**

### 증상

동일한 정면 차량임에도 다음과 같이 새로운 ID가 반복적으로 발급되었습니다.

```text
car ID:1
car ID:8
car ID:13
```

### 원인

초기 추적기는 이전 박스와 현재 박스의 IoU만으로 동일 객체 여부를 판단했습니다. 원거리 차량은 바운딩 박스가 작아 픽셀 단위의 미세한 이동이나 크기 변화만으로도 IoU가 크게 낮아지며, YOLO가 한 프레임에서 검출을 놓치거나 박스 크기를 다르게 산출할 경우 기존 ID와 연결되지 못하고 새 ID가 생성되었습니다.

### 해결

IoU 외에 다음 조건을 추가했습니다.

- 바운딩 박스 중심점 간 거리
- 객체 크기에 따른 허용 이동 거리
- Kalman Filter를 이용한 위치 예측
- 차량 클래스 간 일시적인 분류 변경 허용

매칭 조건은 다음과 같습니다.

```text
IoU가 충분히 높음
또는
중심점 거리가 허용 범위 이내
```

### 검증

초기 버전 대비 ID 변경 빈도는 감소했으나, 완전히 해결되지는 않았습니다.

## 4. 과거에 놓친 ID가 현재 차량의 ID를 가로채는 문제

**상태: 개선 중**

### 증상

동일한 정면 차량의 ID가 다음과 같이 변경된 뒤 이전 ID가 다시 나타나는 현상이 발생했습니다.

```text
ID 1
→ ID 17
→ ID 23
→ 다시 ID 17
```

### 원인

추적 목록에는 YOLO가 놓친 객체의 ID가 여러 프레임 동안 남아 있었습니다. 정상적으로 이어지는 ID와 과거에 놓친 ID가 동일한 우선순위로 현재 검출 결과와 경쟁하면서, 오래된 ID가 현재 차량의 자리를 다시 가져가는 문제가 발생했습니다.

또한 기존 Kalman Filter는 다음 상태만 예측했습니다.

```text
중심 x
중심 y
x 속도
y 속도
박스 너비
박스 높이
```

차량이 카메라에 가까워지며 박스 크기가 커지는 속도는 상태에 포함되어 있지 않았습니다.

### 개선 방향

추적 매칭을 두 단계로 분리합니다.

1차 매칭:

```text
직전 프레임까지 정상적으로 이어진 ID
→ 현재 검출 결과에 우선 연결
```

2차 매칭:

```text
잠시 놓쳤던 ID
→ 1차 매칭 후 남은 검출 결과에만 엄격하게 재연결
```

Kalman Filter 상태는 6개에서 8개로 확장합니다.

```text
중심 x
중심 y
x 속도
y 속도
박스 너비
박스 높이
너비 변화속도
높이 변화속도
```

추가로 다음 조건을 적용합니다.

- 작은 원거리 차량의 중심점 허용 거리 축소
- 박스 면적이 갑자기 크게 변하면 다른 객체로 판단
- 오래 놓친 ID에 재연결 감점 적용
- car, bus, truck과 bicycle, motorcycle 추적 범주 분리
- 놓친 ID의 재연결 가능 프레임 수 제한

### 검증 계획

다음 항목을 결과 영상을 통해 확인할 예정입니다.

- 정면 차량의 ID가 연속적으로 유지되는지
- 측면 차량이 접근할 때 정면 차량의 ID를 가져가지 않는지
- YOLO가 1~2프레임 놓친 뒤 기존 ID로 복귀하는지
- 사라진 과거 ID가 다른 차량에 다시 붙지 않는지
