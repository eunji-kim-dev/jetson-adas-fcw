# FCW 평가셋 (41개)

FCW 경고 기능을 검증하는 데 쓴 영상 목록과 기준이다. 영상 파일은 저장소에 넣지 않았고(`videos/`는 `.gitignore` 대상), 이 폴더에는 영상별 정답·차로 영역 등을 담은 CSV만 있다.

| 구분 | 개수 | 파일 | 용도 |
| --- | ---: | --- | --- |
| 개발 양성 (본 세트) | 16 | `videos.csv` | 규칙 개선·회귀검증 |
| 개발 음성 (정상 주행) | 10 | `videos_negative.csv` | 규칙 개선·회귀검증 (오경보 측정) |
| 홀드아웃 양성 | 5 | `videos_positive_holdout.csv` | 평가만 — 결과로 코드를 고치지 않음 |
| 홀드아웃 음성 | 5 | `videos_negative_holdout.csv` | 평가만 — 결과로 코드를 고치지 않음 |
| 이륜차 | 5 | `videos_twowheel.csv` | 실행·기록만 — 통과 조건에서 제외 |

**개발·회귀검증 26개 / 개발에 쓰지 않은 독립 평가 10개 / 이륜차 5개 보류.** 평가 루프는 41개를 한 번에 돌리지만 결과는 세트마다 따로 채점·보고한다.

## 1. 세트를 나눈 이유

- **본 세트 16개는 전부 경고 대상이다.** 선행차 후방 추돌뿐 아니라 횡단·맞은편 접근·교행처럼 지금 FCW 범위 밖이지만 실제로 위험한 장면도 들어 있다. 그래서 이 세트에서 뜬 경고를 오경보로 세지 않는다.
- **오경보는 음성 세트로 잰다.** 본 세트에는 경고가 필요 없는 영상이 없어서, 정상 주행 10개를 따로 모았다. 규칙을 고를 때는 본 세트의 누락과 음성 세트의 오경보를 같이 봤다.
- **홀드아웃 10개는 규칙을 다 정한 뒤에 골랐다.** 개발에 쓴 영상에만 맞춘 규칙인지 확인하려는 것이다. 결과가 나빠도 이 영상에 맞춰 규칙·임계값·차로 영역을 고치지 않았고, 실패는 실패로 기록했다.
- **이륜차 5개는 검출 단계부터 불안정해 따로 뒀다.** 검출이 없으면 추적·LEAD·TTC가 아예 시작되지 않는다. 그래서 이 세트의 미경고를 LEAD·TTC 로직의 실패로 해석하지 않는다. 막힌 지점도 영상마다 다르다(12는 검출 점수가 끊김, 13은 트랙 시작·LEAD 체류 조건, 14는 배달통을 truck으로 잡음).

## 6. 채점 기준

- **경고 = 화면 배너 DANGER.** `_banner.csv` 기준이고 프레임별 원시 위험 단계는 쓰지 않는다.
- **경고 선행시간 = (충돌 프레임 − 첫 DANGER 프레임) ÷ fps.** 첫 경고가 충돌 뒤면 누락이다. fps가 다른 세트끼리 프레임 수로 비교하지 않는다.
- **대상 기준 채점.** 경고가 떴어도 충돌 대상이 아닌 차에 뜬 것이면 누락이다(예: 이륜차 13은 62프레임에 옆 버스에 경고). 06처럼 대상이 두 대면 둘 다 경고해야 성공이다.
- **오경보는 음성 세트로만 센다.** 본 세트의 범위 밖 위험 장면은 오경보 분모에 넣지 않는다.
- 세트마다 따로 보고하고 하나의 성공률로 합치지 않는다.

## 7. CSV 열

| 열 | 뜻 |
| --- | --- |
| `id` | 영상 이름 (`videos/<폴더>/<id>.mp4`). 원본 파일 이름은 `rename_map.csv` |
| `type` | 원본 라벨의 유형 값 (블랙박스 영상은 숫자 코드, 융합센서 영상은 장면 이름) |
| `group` | 채점용 분류 (`normal`, `cutin`, `crossing`, `edge`, `negative`) |
| `should_warn` | 경고가 필요한 영상이면 1 |
| `collision_frame`, `cf_status` | 충돌 프레임과 그 상태 (`confirmed` 직접 확인, `estimated` 추정, `none` 충돌 없음) |
| `x1,y1 … x4,y4` | 자차 차로 영역(사다리꼴) 네 점, 원본 픽셀 좌표. 왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래 |
| `rx1,ry1 … rx4,ry4`, `road_w_m`, `road_l_m`, `road_frame`, `road_res`, `bonnet_y`, `road_status`, `d0_m` | 노면 네 점과 실제 크기 등 호모그래피 실험용 값. 최종 판정에는 쓰지 않음 |

`labeling_sheet.csv`는 영상을 고를 때 쓴 원본 라벨 정리표다.

## 8. 실행

세트마다 영상 폴더를 따로 준다. `[SKIP]`이 하나라도 나오면 덜 돈 것이다.

```bash
export CROP_MODEL=models/yolov8n_288x640.onnx CROP_INPUT=288x640
export LEAD_RULE=overlap,history,gap,passby,gate,bonnet,hold,rank,bottom,edge,cropedge,rawconfirm

bash scripts/run_eval_set.sh eval/videos.csv tensorrt_fp16
bash scripts/run_eval_set.sh eval/videos_twowheel.csv tensorrt_fp16
VIDEO_DIR=videos/negative          bash scripts/run_eval_set.sh eval/videos_negative.csv tensorrt_fp16
VIDEO_DIR=videos/holdout           bash scripts/run_eval_set.sh eval/videos_positive_holdout.csv tensorrt_fp16
VIDEO_DIR=videos/holdout/negative  bash scripts/run_eval_set.sh eval/videos_negative_holdout.csv tensorrt_fp16

python3 tools/evaluate_fcw.py --videos eval/videos.csv results/eval/<결과 폴더>
```

대상 기준 채점은 `tools/compare_lead_target.py`로 한다.
